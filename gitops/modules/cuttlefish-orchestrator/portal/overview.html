Horizon SDV Module

Cuttlefish Orchestrator

Fleet management control plane, Spanner metadata store, and Cuttlefish Web Console behind Horizon Keycloak OIDC and GKE Gateway routing.

Capabilities

  • Provision and manage virtualized Cuttlefish Android hosts on private VPC Compute Engine instances.
  • Launch multi-display Cuttlefish virtual devices backed by Cloud Spanner fleet state and GCS artifact staging.
  • Stream interactive Cuttlefish displays and console sessions directly in the browser via /cuttlefish-orchestrator/.

Architecture & Integration

  • Authentication: GKE Gateway routes /cuttlefish-orchestrator/ through oauth2-proxy authenticated against Horizon Keycloak (administrators and developers groups).
  • Persistence: Cluster-mode Config Connector provisions a regional Cloud Spanner instance (100 PU) and schema v87 database, seeded idempotently at Sync Wave 4.
  • Teardown: Argo CD PreDelete cleanup scales the API to zero and deletes managed GCE host VMs before removing Kubernetes and Spanner resources.
Prerequisites: Ensure the Cuttlefish host VM image family (cco-host) has been built in the target project (workloads-android / storage-gcs pipelines) before launching devices.
